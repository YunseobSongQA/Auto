혼자 쓰고 끝내지 않도록 만들었습니다. 같은 팀원이나 같은 프로젝트에 있는 사람이라면 누구나 그대로 열어 쓰고 이어서 고쳐 쓸 수 있게, 코드와 실행 결과를 전부 공개해 두었습니다.

지금까지 만든 것 — 증적 관리 플랫폼(QASS) · 기획서 분석(PRD2TC) · 자동 테스트 4종. 자동 테스트의 대상은 제가 직접 만들어 운영 중인 QASS입니다.
